# 💙 Todo App — Task Management

A modern and responsive Todo Application built using **HTML, CSS, and JavaScript**. This application helps users organize daily tasks with simple CRUD functionality and a professional blue-purple gradient design.

## ✨ Features

- ➕ **Create Tasks:** Add new tasks easily.
- 📋 **Read Tasks:** View all saved tasks in a clean task list.
- ✏️ **Update Tasks:** Edit existing task descriptions.
- 🗑️ **Delete Tasks:** Remove tasks with confirmation.
- ✓ **Complete Tasks:** Mark tasks as completed using a tick button.
- 💾 **Local Storage:** Save tasks in the browser so they remain available after refreshing the page.
- 🎨 **Modern UI:** Professional gradient background, clean cards, and attractive buttons.
- 📱 **Responsive Design:** Works on desktop, tablet, and mobile screens.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- DOM Manipulation
- `querySelector()` and `querySelectorAll()`
- Browser Local Storage

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all three files are in the same folder.
4. Open `index.html` in your browser, or run it using the Live Server extension in VS Code.
5. Start adding and managing your tasks!

## 💡 How It Works

The application uses JavaScript to perform CRUD operations:

| Operation | Description |
|---|---|
| Create | Add a new task |
| Read | Display saved tasks |
| Update | Edit an existing task |
| Delete | Remove a task |
| Complete | Toggle a task's completion status |

Tasks are stored in the browser using `localStorage`, so they persist across page refreshes in the same browser.
